# A local navigable BioMCP site over a SQLite entity layer: entity pages keyed by public ids (gene:HGNC:1097, article:pmid:N, trial:NCT...), links between them, full-text search, cache age and sources on every page, restricted sources never exported, and the downloaded datasets (WHO, GTR, EMA, DDInter, CVX, GenCC) loaded into a second database for pages and search

Status: open.

Kind: idea
When: after 2134 lands

## Problem

A local navigable BioMCP site over a SQLite entity layer: entity pages keyed by public ids (gene:HGNC:1097, article:pmid:N, trial:NCT...), links between them, full-text search, cache age and sources on every page, restricted sources never exported, and the downloaded datasets (WHO, GTR, EMA, DDInter, CVX, GenCC) loaded into a second database for pages and search. clinicians browse what BioMCP already fetched as linked pages instead of rerunning commands.
