BioMCP now accepts the genomic indel forms its variant cards can print,
including MyVariant repeat identities. Follow-up commands remain usable because
exact repeat lookups encode brackets at the request boundary.

Parser guidance, CLI help, user documentation, and executable specifications
now describe and enforce the same supported forms.
