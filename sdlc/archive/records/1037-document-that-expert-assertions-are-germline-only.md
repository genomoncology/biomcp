# Document that expert assertions are germline only

ERepo help, Markdown output, and public guidance now identify germline-only
interpretations and route somatic questions to BioMCP's CIViC commands. This
prevents empty ERepo results from implying that a somatic question lacks
available evidence, without changing retrieval or structured responses.
