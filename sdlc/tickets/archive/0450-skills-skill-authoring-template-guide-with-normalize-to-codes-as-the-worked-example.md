# Skills: skill-authoring template + guide, with normalize-to-codes as the worked example

AutoCAB-style work is "turn everyday workflows into reusable agent skills" — exactly what BioMCP's 15-playbook + `*.ladder.json` model already demonstrates. Generalize that into a domain-neutral **authoring template + guide** so the pattern is reusable, and ship **one worked example** playbook that exercises it: normalize a free-text clinical/guideline term to standard ontology codes via `discover`. The example doubles as grounding support for clinical-structuring agents (it shows how to map extracted terms to MONDO/HPO/ICD-10/SNOMED/RxNorm). Serves the community/skills and awareness goals.
