# GTR foundation: diagnostic entity backbone

BioMCP has no answer for "what test exists for this gene/disease?" — a daily question in precision medicine and clinical genetics. Spike 230 proved that NCBI's Genetic Testing Registry (GTR) provides 64,374 tests with 97% coverage of clinically relevant genes. The spike produced a complete data model, CLI surface proposal, and module boundaries. This ticket builds the foundation.
