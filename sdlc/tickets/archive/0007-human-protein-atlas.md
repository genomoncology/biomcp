# Add Human Protein Atlas tissue expression

BioMCP has RNA-level tissue expression from GTEx but no protein-level tissue data. Researchers want to know where a protein is actually expressed, not just where the transcript is detected. Human Protein Atlas provides protein-level tissue and cell expression, pathology data, and subcellular localization — all through a free REST API with no auth.
