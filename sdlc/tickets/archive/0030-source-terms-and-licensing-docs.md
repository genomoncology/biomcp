# Document source terms, licensing, and API key requirements

BioMCP federates 20+ public biomedical databases, each with its own terms of use, licensing, and API key requirements. BioMCP itself is MIT-licensed, but users need to understand that the upstream sources they're querying have their own policies — some are fully open (PubMed, Reactome), some require free API keys (OncoKB, DisGeNET, UMLS), and some have academic-use-only or attribution requirements (KEGG, gnomAD). There's currently no single place in the repo that covers this. Users and institutions evaluating BioMCP need a clear, honest picture of the licensing landscape.
