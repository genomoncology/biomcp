# Add ComplexPortal protein complex data

"What complex is this protein part of?" is a common question in molecular biology. ComplexPortal (EBI) provides curated protein complex data — the publicly accessible equivalent of CORUM. The GeneAgent paper identified this as a gap when reproducing its protein complex analysis workflow. ComplexPortal has a small, clean REST API with no auth required.
