# Spike: GTR and diagnostic entity data landscape

BioMCP has no answer for "what test exists for this gene/disease?" — a daily clinical question in precision medicine. NCBI's Genetic Testing Registry (GTR) has 65K+ registered tests mapping genes to available diagnostics. WHO Prequalification has an in vitro diagnostics list. FDA has 510(k) and PMA databases for cleared/approved devices. Before committing to a new `diagnostic` entity, we need to understand the data landscape: what's available, what the schemas look like, what's queryable via API vs download, and whether the data is rich enough to justify a first-class entity.
