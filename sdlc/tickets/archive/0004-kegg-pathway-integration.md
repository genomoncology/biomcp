# Add KEGG pathway integration

BioMCP's pathway entity currently uses only Reactome. KEGG is the other major pathway database — ubiquitous in biology publications, referenced in virtually every pathway analysis paper. Adding KEGG as a second pathway source gives researchers broader pathway coverage and cross-validation between databases. This is a high-value addition, but it is not ready to queue until BioMCP confirms the upstream use/distribution terms are compatible with BioMCP's public CLI and docs posture.
