# Give the MCP tool catalog real headroom under its budget

The MCP catalog budget now admits one search-sized typed tool or a normal
sentence while remaining a hard gate. The measurement prints every catalog
size and, on a breach, reports each ceiling and the largest descriptions so
contributors can act on the failure.
