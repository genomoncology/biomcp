# Put the useful population numbers where they can be seen

Variant population Markdown now leads with overall exome and genome frequencies,
highest ancestry frequencies, FAF95, and quality status. The documented
`population-details` selector retains every ancestry-table row while JSON stays
unchanged for programmatic callers.
