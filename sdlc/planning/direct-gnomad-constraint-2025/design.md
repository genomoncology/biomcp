## Shared API and storage

Producer0712's `sdlc/planning/0712-direct-gnomad-constraint.md` defines the same API in the library. Add a separate `adapters::gnomad_constraint` module. Export `GnomadGeneConstraint`, `GnomadGeneConstraintProjection`, `GnomadGeneConstraintTarget` and `GnomadConstraintError`. The projection owns exactly transcript plus four optional finite metrics with private fields, borrowing getters, Clone, PartialEq and type-only Debug. It has fallible `try_new(transcript, pli, loeuf, mis_z, syn_z)` and infallible all-absent `empty`. No domain serialization derive, mutable mirror or new dependency.

`GnomadGeneConstraint::deserialize_gene(D)` consumes the original embedded nonnull gene member through the existing generic HTTP decoder. `GeneConstraintResponse.gene` uses a local optional Deserialize wrapper, following the population wrapper pattern. Missing/null `gene` remains None; the library never sees the GraphQL envelope. Keep `GraphQlResponse`, `GraphQlError`, `GeneConstraintResponse` and `parse_gene_constraint_response` as product policy. Change the mapper to return/move the shared record directly after existing error classification. A compatibility reexport under `GnomadConstraintData` may preserve the symbol, but must alias the shared type and own no fields.

Keep `GeneConstraint` only as a product metadata envelope. Replace its five public value fields with one shared `record` field and retain `source`, `source_version`, `reference_genome`. Use `#[serde(flatten)]` with narrow serialize/deserialize functions on the record: serialize `as_constraint_target()`, deserialize through `deserialize_constraint_target(D)`. The borrowed encoder emits only present `pli`, `loeuf`, `mis_z`, `syn_z`, `transcript`; the existing product fields remain flattened at the same JSON level. Metadata remains required by the product decoder. Do not accidentally expose a `record` key or change omitted optionals to explicit nulls. Validate flattened decode with the real Gene Deserialize caller rather than relying on direct-encoder proof alone.

MiniJinja serializes this same product envelope through the borrowed bridge. It receives the existing flat fields without a second template model or a field-by-field mirror. `fetch_constraint_section` moves the shared record into metadata; empty/unavailable paths construct `empty()`. Section availability, outcome and timing borrow shared getters. Update both serial and ParallelTop code. Product metadata strings and section rules remain product decisions. No library method takes application source labels or executes a request.

## Source, target and privacy admission

Source `canonical_transcript_id` accepts missing/null or arbitrary string, applies current `str::trim`, and drops blank. `gnomad_constraint` accepts missing/null or object. All four metrics accept missing/null or finite numbers without ranges, rounding, sign or clinical constraints. Preserve `pLI` plus `pli` alias; `oe_lof_upper` becomes `loeuf`. Null/missing metrics keep the transcript. A nonnull all-empty source gene remains Some(record); an absent gene stays None. Existing local decoding already collapses missing and null to None; this design preserves that behavior without inventing certainty or metric defaults.

Known wrong types, duplicate known fields including aliases, and nonfinite generic-deserializer values fail. Unknown fields at either source nesting level remain tolerated and fully consumed. Preserve existing HTTP/content-type, source body ceiling and Serde recursion admission; do not substitute the population-specific 512KiB ceiling for the current gene path. Embedded decoder errors and shared Debug return only static safe messages/type names; they never format or chain private source values. No source Value or serialize/reparse bridge is introduced.

Target `deserialize_constraint_target(D)` accepts the existing target names, missing/null fields, unknown fields and finite metrics. It preserves transcript strings including blank/whitespace exactly, because current Gene Deserialize does not apply source normalization. Borrowed target output omits absent values and preserves present blanks. It does not accept source aliases as target fields. Product metadata is not shared meaning; its decoder keeps existing admission.

GraphQL error handling stays local: no gene and at least one nonblank message, all equal to `Gene not found` ignoring case after trim, yields absence. Other nonempty errors fail, including errors beside usable data. Nonempty errors without meaningful messages use `GraphQL request failed`. Empty errors behave as no errors. Existing internal provider error diagnostics remain product-owned; public sections retain the static unavailable message and no error-text payload. Sanitization in the new embedded decoder does not authorize unrelated changes to HTTP diagnostics or logging.

Default/unrequested constraint remains omitted and makes no gnomAD call. Requested absence/all-empty yields an empty section with metadata. Transcript alone counts as data even when every metric is absent. Errors/timeouts yield unavailable with an empty record and the existing static message. JSON provenance credits healthy data/empty according to existing outcomes and never presents unavailable as healthy evidence. Markdown respects source-state payload/empty gates and existing score formatting. No unrequested metadata or provider-only unknown field may escape through JSON, Markdown or MCP.
